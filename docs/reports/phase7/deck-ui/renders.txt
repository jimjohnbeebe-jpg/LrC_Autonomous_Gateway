Headless renders of the Deck's own drawing code (Phase 7 row 4c, pre-run finding 3 in docs\reports\phase7\deck-ui.md).

Claude Code ran, on branch phase-7/deck-ui, 2026-10-05 local, after `node build-ui.ts` in hud\:
  node headless.mts            (every state at 1200 CSS px)
  node headless.mts V-pick 1800 / C-converged 1800
It copies hud\ui-dist, adds a harness page that calls the Deck's own view() and html() (ui-dist\view.js,
render.js) for made-up states validated by the engine's hudChannelStateSchema, and screenshots each in
headless Microsoft Edge (--screenshot), so no window opens on the desktop. The thumbnails are flat colours
made with sharp. The script ran from Claude Code's scratchpad; it is kept here verbatim, not as a file to run
(rule 01).

Files: renders\<state>-<css width>.png. States: W working, P approve, C converged (armed: Abort armed with
the keyboard), cap = all passes used (Q6), V the pick (chosen: card B chosen with the keyboard; after: copy B
picked), sent = a click waiting for its answer, D = Claude not connected, T = another photo selected,
undone = a pass undone, Done = accepted; -bar = the 44 px bar.

----- headless.mts, verbatim -----
