## Consequences / open questions

- **#111, pick flags:** `setRawMetadata("pickStatus", 1 | -1 | 0)` in a write gate is enough for a flag tool.
- **#112, title, caption, headline:** `setRawMetadata` writes them, and `getFormattedMetadata` reads them back.
- **#139 gap 2, a folder filter:** `findPhotos` "folder" matches the folder's **name**, not its path, as the reference describes.
  - Two folders with the same name are therefore not told apart [inference].
  - `getFolderByPath` + `getPhotos` takes a full path and found the photo.
  - A tool that takes a path should use the second way.
- **#139 gap 4 and #111, stacks:**
  - A plugin can make a stack only by importing a file, stacked with a photo already in the catalog. Photos already in the catalog cannot be stacked [handle: Pre-run findings, the reference; the results, `import_stack`].
  - Stacking bracket triples that are already imported has no SDK call [inference: from the reference].
  - The stack state can be read on any photo.
- **gps / gpsAltitude on a photo with a position** stays [unverified]. Phase 6 wrote and read `gps` [handle: LR_SDK_NOTES, "Recorded in Phase 6 — 2026-10-03, keywords and GPS"]; `gpsAltitude` has not been read with a value.
